ARMOUR CRAFTER
Script variant: Armour Crafter (Standard)

BEFORE YOU START

- Have the materials for the armour you want to make ready, along with your bank preset.

STEPS TO RUN

1. Put the material used to open the armour-crafting interface on your action bar. In Setup > Hotkeys, assign [Skillbar] to that slot.

2. In Setup > Hotkeys, set [Bank Preset] to the in-game hotkey for the preset containing your supplies. The script presses this hotkey when banking.

3. Open Setup > Coordinates and capture [Bank] on the banker, chest or bank booth used on the return leg.

4. Capture [Item] on the armour item you want to make in the crafting interface.

5. Check the Setup Checklist and resolve any Missing or Invalid entries before starting.

6. Press Start and choose how many runs you want to complete. Watch the first cycle to make sure the clicks and banking work correctly.

ADDITIONAL SCRIPT NOTES

- Timing: Keep the default Sleep values unless actions happen too early or too late. You can adjust them in Setup > Timer; test a full cycle after each change.

FRAME MAKER
Script variant: Fort Forinthry / Frame Maker (Standard)

BEFORE YOU START

- Have the supplies and bank preset ready for woodworking frames.

- Capture the bank and workstation coordinates from the standing positions given in the steps below.

- START THIS SCRIPT STANDING SOUTH OF THE BANK CHEST.

STEPS TO RUN

1. In Setup > Hotkeys, set [Bank Preset] to the in-game hotkey for the preset containing your supplies. The script presses this hotkey when banking.

2. Open Setup > Coordinates and capture [Bank Prime] while standing SOUTH of the bank chest.

3. Capture [Woodworking Bench] while standing SOUTH of the bank chest.

4. Capture [Bank Main] while standing NORTH of the woodworking bench. These are two views of the same bank; capture each separately from the specified tile.

5. Check the Setup Checklist and resolve any Missing or Invalid entries before starting.

6. Press Start and choose how many runs you want to complete. Watch the first cycle to make sure the clicks and banking work correctly.

ADDITIONAL SCRIPT NOTES

- Timing: Keep the default Sleep values unless actions happen too early or too late. You can adjust them in Setup > Timer; test a full cycle after each change.

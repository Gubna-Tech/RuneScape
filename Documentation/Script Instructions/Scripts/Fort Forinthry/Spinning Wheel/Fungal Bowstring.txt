FUNGAL BOWSTRING
Script variant: Fort Forinthry / Spinning Wheel / Fungal Bowstring (Standard)

BEFORE YOU START

- Bring enough fungal bowstring materials for the runs you plan to complete. This Fungal Bowstring variant does not bank or load a preset during its crafting loop; it repeatedly clicks the fungal spinning-wheel target and presses Space.

- Keep only the materials for the fungal bowstring you want to make so the spinning-wheel interface selects the intended product.

STEPS TO RUN

1. Open Setup > Coordinates and capture [Spinning Wheel - Fungal Only] on the spinning wheel from the tile where you will run the script. This is the only saved coordinate used during fungal-bowstring runs.

2. Check the Setup Checklist and resolve any Missing or Invalid entries before starting.

3. Press Start and choose how many runs you want to complete. Check the first spin and confirm the selected materials craft correctly; this variant does not return to the bank.

ADDITIONAL SCRIPT NOTES

- Timing: Keep the default Sleep values unless actions happen too early or too late. You can adjust them in Setup > Timer; test a full cycle after each change.

FIREMAKING
Script variant: Prifddinas / Firemaking (Standard)

BEFORE YOU START

- At the Prifddinas bonfire, set its selected activity to firemaking before capturing coordinates.

- Fire-spirit collection is NOT supported.

STEPS TO RUN

1. In Setup > Hotkeys, set [Bank Preset] to the in-game hotkey for the preset containing your supplies. The script presses this hotkey when banking.

2. Open Setup > Coordinates and capture [Bank Prime]. These coordinates are set when standing at the banker.

3. Capture [Bonfire] on the bonfire you use for firemaking.

4. Capture [Bank Main] while standing at the bonfire. These are two views of the same bank; capture each separately from the specified tile.

5. Check the Setup Checklist and resolve any Missing or Invalid entries before starting.

6. Press Start and choose how many runs you want to complete. Watch the first cycle to make sure the clicks and banking work correctly.

ADDITIONAL SCRIPT NOTES

- Timing: Keep the default Sleep values unless actions happen too early or too late. You can adjust them in Setup > Timer; test a full cycle after each change.

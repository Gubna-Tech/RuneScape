JEWELLERY CRAFTER
Script variant: Jewellery Crafter (Standard)

BEFORE YOU START

- Have the metal bars and any gems for your chosen jewellery ready.

- Capture the bank and furnace coordinates from the standing positions described below.

STEPS TO RUN

1. In Setup > Hotkeys, set [Bank Preset] to the in-game hotkey for the preset containing your supplies. The script presses this hotkey when banking.

2. Open Setup > Coordinates and capture [Bank Prime] while standing at the bank.

3. Capture [Furnace] on the furnace while you are standing at the bank, before walking over to craft.

4. Capture [Bank Main] while standing at the furnace. These are two views of the same bank; capture each separately from the specified tile.

5. Capture [Bar] on the metal type you want to use in the furnace interface.

6. Capture [Item] on the jewellery item you want to make after selecting the metal.

7. Check the Setup Checklist and resolve any Missing or Invalid entries before starting.

8. Press Start and choose how many runs you want to complete. Watch the first cycle to make sure the clicks and banking work correctly.

OPTIONAL SETTINGS

- [Scroll]: Only enable when the desired interface item is off-screen; change scroll bounds in Setup > Script Config.

ADDITIONAL SCRIPT NOTES

- Timing: Keep the default Sleep values unless actions happen too early or too late. You can adjust them in Setup > Timer; test a full cycle after each change.

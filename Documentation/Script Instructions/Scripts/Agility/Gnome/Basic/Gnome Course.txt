GNOME COURSE
Script variant: Agility / Gnome / Basic (Standard)

BEFORE YOU START

- Capture the obstacles in course order. For each one, stand on the tile you would use to click it after finishing the previous obstacle.

- Capture that target before moving on.

- Use your normal starting tile for the first obstacle, and keep the same camera angle and zoom throughout.

- Begin in front of the log balance.

- Capture Prime here, then capture Main from the obstacle-pipe exit.

STEPS TO RUN

1. Open Setup > Coordinates and capture [Log balance prime] while standing in front of the log balance.

2. Capture [Obstacle net 1] from its approach tile, before clicking it.

3. Capture [Tree branch 1] from its approach tile, before clicking it.

4. Capture [Balance rope] using a small fixed click area, not a dynamic rectangle. The rope has a narrow target.

5. Capture [Tree branch 2] from its approach tile, before clicking it.

6. Capture [Obstacle net 2] from its approach tile, before clicking it.

7. Capture [Obstacle pipe] from its approach tile, before clicking it.

8. Capture [Log balance main] from the obstacle-pipe exit after finishing the course. Prime and Main are the same target viewed from different tiles. Capture each position separately.

9. Return to the tile where you captured Prime, keep the same camera angle and zoom, and check that every obstacle shows Ready in the Setup Checklist.

10. Press Start and choose how many laps you want to run. Watch the first lap to make sure each obstacle is clicked correctly.

ADDITIONAL SCRIPT NOTES

- Timing: Keep the default Sleep values unless actions happen too early or too late. You can adjust them in Setup > Timer; test a full cycle after each change.

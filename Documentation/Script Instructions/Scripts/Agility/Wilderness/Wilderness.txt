WILDERNESS
Script variant: Agility / Wilderness (Standard)

BEFORE YOU START

- Capture the obstacles in course order. For each one, stand on the tile you would use to click it after finishing the previous obstacle.

- Capture that target before moving on.

- Use your normal starting tile for the first obstacle, and keep the same camera angle and zoom throughout.

- FOR BEST RESULTS, USE SOUTH-FACING CAMERA (do not adjust camera after selecting face-south).

- YOU MUST WEAR THE AGILITY SKILLCAPE TO RUN THIS SCRIPT!

- START THIS SCRIPT ON THE TILE NORTH OF THE OBSTACLE PIPE.

STEPS TO RUN

1. Open Setup > Coordinates and capture [Obstacle pipe prime] while standing in front of the obstacle pipe. Stand on the tile NORTH of the obstacle pipe for Prime.

2. Capture [Ropeswing] from its approach tile, before clicking it.

3. Capture [Stepping stone] from its approach tile, before clicking it.

4. Capture [Log balance] from its approach tile, before clicking it.

5. Capture [Cliffside] from its approach tile, before clicking it.

6. After climbing the cliffside, capture [Obstacle pipe main] from the return approach before entering the pipe. Prime and Main are the same target viewed from different tiles. Capture each position separately.

7. Return to the tile where you captured Prime, keep the same camera angle and zoom, and check that every obstacle shows Ready in the Setup Checklist.

8. Press Start and choose how many laps you want to run. Watch the first lap to make sure each obstacle is clicked correctly.

ADDITIONAL SCRIPT NOTES

- Timing: Keep the default Sleep values unless actions happen too early or too late. You can adjust them in Setup > Timer; test a full cycle after each change.

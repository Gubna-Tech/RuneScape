PLANK + REFINED - MES
Script variant: Fort Forinthry / Plank + Refined (Menu Entry Swapper)

BEFORE YOU START

- IMPORTANT: Load the correct bank preset manually before starting. Menu Entry Swapper (MES) reuses your last loaded preset instead of pressing a Bank Preset hotkey.

- Have the supplies and bank preset ready for planks and refined planks.

- Capture the bank and workstation coordinates from the standing positions given in the steps below.

- START THIS SCRIPT STANDING SOUTH OF THE BANK CHEST.

STEPS TO RUN

1. Open Setup > Coordinates and capture [Bank Prime] while standing SOUTH of the bank chest.

2. Capture [Sawmill - First] while standing SOUTH of the bank chest.

3. Capture [Bank Main] while standing NORTH of the sawmill. These are two views of the same bank; capture each separately from the specified tile.

4. Capture [Sawmill - Second] while standing NORTH of the sawmill.

5. Check the Setup Checklist and resolve any Missing or Invalid entries before starting.

6. Press Start and choose how many runs you want to complete. Watch the first cycle to make sure the clicks and banking work correctly.

ADDITIONAL SCRIPT NOTES

- Timing: Keep the default Sleep values unless actions happen too early or too late. You can adjust them in Setup > Timer; test a full cycle after each change.
